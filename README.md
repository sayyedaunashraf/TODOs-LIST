# ✅ TODOs LIST

A simple and clean **Todo List web application** to help users manage their daily tasks easily.

🔗 **Live Demo:**  
https://todos-list-ashen-rho.vercel.app/


## 📌 About the Project

TODOs LIST is a basic web application where users can add, view, and manage their daily tasks.  
This project is built using **HTML, CSS, and JavaScript** and is ideal for beginners.


## ✨ Features

- ➕ Add new tasks  
- 📋 View all tasks in a list  
- 🧹 Clear tasks easily  
- 💻 Simple and responsive user interface  


## 🛠️ Built With

- HTML  
- CSS  
- JavaScript

## Future Improvements
